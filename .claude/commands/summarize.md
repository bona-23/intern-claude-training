# Summarize

## Purpose

Give the intern a quick, shareable summary of the current work session - useful for updating a supervisor or personal notes without re-reading the whole session.

## Process
1. Review what happened in this session: files edited, commands run, and questions asked.
2. Write exactly 3 sentences covering:
  - what was accomplished
  - what broke or was surprising
  - what is still open or unfinished
3. Print the 3-sentence summary directly to the terminal so the intern can copy it into a note or share it with their supervisor.

## Notes
  - Keep it to exactly 3 sentences - no more, no less.
  - Be concrete: name the actual files or commands involved, not vague descriptions.
